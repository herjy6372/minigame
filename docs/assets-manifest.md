# 게임 리소스 명세서

## 1. 공통 스타일

- 표현 방식: 밝고 친근한 캐주얼 2D 게임 일러스트
- 주요 색상: 주황색 고양이, 따뜻한 나무색, 밝은 교실 색상
- 외곽선: 얇고 깨끗한 검정색 외곽선
- 이미지 내 글자: 사용하지 않음
- 이미지 비율: 정사각형 1:1
- 사용 목적: `미로 탈출 한 칸 모험`의 캐릭터, 배경, 입구·출구 및 효과음

## 2. 이미지 리소스

| 파일 경로 | 역할 | 사용 위치 | 투명 배경 |
|---|---|---|---|
| `minigame/images/cat.png` | 방향별 고양이 캐릭터 | 미로 안의 플레이어 위치 | 예 |
| `minigame/images/background.png` | 나무 바닥의 교실 배경 | 게임 영역 전체 | 아니요 |
| `minigame/images/door.png` | 열린 교실 문 | 미로의 입구와 출구 | 예 |

## 3. 사운드 리소스

| 파일 경로 | 역할 | 재생 시점 | 반복 |
|---|---|---|---|
| `minigame/sounds/cat-meow.wav` | 고양이 울음 효과음 | 게임 시작 및 게임 종료 시 | 아니요 |

## 4. 적용 규칙

- 모든 파일명과 폴더명은 영문 소문자와 하이픈을 사용한다.
- HTML과 JavaScript에서는 위 표에 작성된 상대 경로를 그대로 사용한다.
- 고양이 이미지는 이동 방향에 맞는 모습을 표시한다.
- 고양이와 문 이미지는 투명 배경을 유지한다.
- 교실 배경은 게임 영역 전체를 채우되 이미지 비율이 찌그러지지 않게 적용한다.
- 문 이미지는 동일한 파일을 입구와 출구에 재사용할 수 있다.
- 고양이와 문은 미로 칸 안에 들어오도록 크기를 조절한다.
- 고양이 울음소리는 한 번만 재생하며 동시에 여러 번 겹쳐 재생되지 않게 한다.
- 사운드를 재생할 수 없는 환경에서도 게임 진행에는 문제가 없어야 한다.
- 이미지가 로드되지 않으면 배경색이나 이모지로 대체할 수 있게 한다.
